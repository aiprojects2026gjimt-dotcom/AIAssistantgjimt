DASHBOARD COUNTING RULE - V4

OVERALL REGISTRATION:
Every donor where Present = YES.

NON GIANJYOTIAN REGISTRATION:
ONLY donors where:
Present = YES
AND
Registration Type = Non Gianjyotian

GIANJYOTIAN REGISTRATION:
ALL OTHER donors where Present = YES.
Therefore Pre-Registered, New Entry, Outsider, or any other Registration Type is counted in Gianjyotian unless the Registration Type is exactly Non Gianjyotian.

This update intentionally follows the user's requested Registration Type rule only.
